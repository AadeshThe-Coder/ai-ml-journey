## 🎯 Goal

Become a job-ready **AI/ML Engineer** by building, not just watching. By the end of this journey I will have:

- A strong base in **Python, SQL, NumPy, Pandas** and the **maths** behind ML
- Hands-on skill in **classical ML** (scikit-learn, XGBoost) and **deep learning** (PyTorch)
- Real experience with **LLMs, RAG, AI agents and evals**
- **4 deployed portfolio projects** with live demos
- Production skills: **FastAPI, Docker, CI/CD, cloud deployment, monitoring**
